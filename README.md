Vice Coast turns any photo into GTA-style cover art: pick one of four multi-panel poster layouts, drop in your own photos (or the included samples), crop and position each panel by dragging, write a big bold caption with a neon script sub-caption, choose a sunset or neon colour grade, and export a full-resolution PNG in 1080×1080, 1080×1350 or 1920×1080. It runs entirely offline in the browser — photos never leave your machine — with a live preview that shows exactly what the export will look like.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
